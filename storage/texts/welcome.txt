Welcome to Aurora-32!

ASFS2 stores executables, directories and editable text.
Use ls, tree, cat docs/welcome.txt or run editor.
quickrun skips checksum comparisons: use trusted images only.
Use ls tinyc for sources; run compiler to compile them on Aurora-32.

Text edits live in the simulated EEPROM, not this host source file.
Export the EEPROM image in Digital before reloading or closing it.
