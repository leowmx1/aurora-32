# Aurora-32 系统内核

本目录只保存内核源码、构建脚本、说明和内核产物。用户库、用户程序及其
产物位于同级的 `../用户程序/` 目录。Aurora-32 地址均为硬件字地址。

## 内存与入口

- 内核 ROM 从 `0x00000000` 开始，首字固定跳到 `_start`。
- 用户 UROM 从 `0x08000000` 开始，URAM 从 `0x09000000` 开始。
- `_start` 先初始化 KSP/KFP，再构造首个用户进程的 IRET 现场。

## 中断与调度

| IVT 字地址 | 用途 |
|---:|---|
| `0x03000001` | 键盘硬件中断 |
| `0x03000002` | Telnet 中断（预留） |
| `0x03000004` | 用户态越界访存 |
| `0x03000005` | 用户态非法指令 |
| `0x03000007` | 定时器中断 |

定时器设备地址是 `0x07000000`。ISR 先读取该地址应答，再保存完整
`FLAGS/PC/r0-r15` 现场。当前调度器在一个系统进程和一个用户进程间
固定切换；用户回调也可被定时器抢占并稍后继续。

## 系统调用与用户回调

用户程序执行 `INT <aurora_syscall_entry 的 ROM 字地址>`。ABI 使用 `r0` 传递
请求号和返回值，`r1-r3` 传递参数。目前实现终端输出、键盘队列读取、
键盘回调订阅、yield 和回调返回。

键盘回调前，内核把被打断的用户现场保存到 PCB，在专用回调 KSP 上构造
新现场，并用 `PUSHU` 向 USP 压入用户返回跳板。回调普通 `RET` 到跳板后，
由私有系统调用重建原用户现场并 `IRET`。

## 构建

```powershell
.\build.ps1
```

产物位于 `build/kernel.s`、`build/kernel.o`、`build/kernel.bin` 和
`build/kernel.hex`。将 `kernel.hex` 加载到 ROM，再从 `../用户程序/` 选择一个
用户 HEX 加载到 UROM。
