# Screen Snake

160×100 显存版贪吃蛇。原终端版 `snake` 已移除，现在使用 `snake-screen` 构建目标。
完整说明见 [docs/user_program/snake-screen/README.md](../../../docs/user_program/snake-screen/README.md)。

```powershell
.\build-tools\build.ps1 -Program snake-screen
```

加载配套 `kernel/build/kernel.hex` 到 ROM，`build/snake-screen.hex` 到 UROM。
不需要屏幕完成中断，只需要绘制完成后 busy 自动清零。
文字使用预计算 6×10 双色位图，每字符一次系统调用，包含背景擦除；地图仍按矩形局部更新。
需使用支持位图请求 28、Sleep 请求 29 的配套内核。
运行中按下一步剩余时间 Sleep，键盘可提前唤醒；未开始/暂停时 WaitEvent。
结束旋律期间每 20ms Sleep 后检查结束状态，绘图等待仍是 Busy/Yield。
MIDI 地址区 0x0A，启动选择音色 0：开局三音提示、轻声循环背景旋律、吃食物三音上行、
出局四音下行、胜利四音上行。单通道音效临时替换背景音乐，不阻塞游戏。
背景采用《贪吃蛇大作战》开头四小节主旋律的单音精简版，保留附点节奏和休止。
声音默认开启；M/m 随时切换音乐和音效总开关，不打印终端。
暂停立即松开音符，继续时恢复背景；出局/胜利播放完短旋律再退出，Q 立即退出。
必须加载本版配套内核：音序器由内核 tick 推进，不依赖绘图速度；吃食物音效结束后续播背景原位置。
PC 引脚接数据 bit 8；退出/异常由内核兜底释放活动音符。

空格开始，WASD 转向，P/空格暂停，+/- 调速，M 切换声音，Q 退出。
深灰蓝背景，金色大块为蛇头，柔和绿色为蛇身，珊瑚色小块为食物；顶部 S 为分数、T 为毫秒/步。
初始 20 ms/步，最快 10、最慢 150；绘制耗时另计。启动时向终端打印一次操作帮助，
游戏期间不打印，退出时输出结果或错误诊断。
