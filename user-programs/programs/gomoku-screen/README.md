# Screen Gomoku

160×100 显存版双人五子棋，保留 5×5 棋盘、连续五子获胜、填满平局。
浅木色棋盘，黑/白实心圆分别为玩家 1/2，每颗圆用两块 10×5 透明位图，外观不变。
输入 A3 / 3A 均可，支持小写；
两字符自动落子，退格/Esc 清空待输入，Q 退出。不回显坐标，右侧显示玩家和结果。
第一字符高亮对应行/列边框；第二字符恢复边框、绘制棋子并更新 P1/P2 数字。
所有屏幕文字使用预计算 6×10 双色位图，每字符一次提交，字形与颜色不变。
普通落子的第二字符现为 4 条恢复边框 + 2 块棋子位图 + 1 次数字位图，需支持位图请求 28 的配套内核。
获胜时在五连子的每颗棋子中心添加红色标记，保留黑白外圈，画完才退出。
若同时连成多条，按原判断顺序标记第一条；平局/主动退出不添加标记。
启动时在终端打印一次坐标、高亮及退出操作帮助，屏幕不显示 Q QUIT。
正常游戏不打印终端，结束时打印结果；局部更新棋子，图形 Busy/Yield 轮询，无完成 IRQ。

```powershell
.\build-tools\build.ps1 -Program gomoku-screen
```

加载配套 `kernel/build/kernel.hex` 到 ROM，本目录 `build/gomoku-screen.hex` 到 UROM。
详细说明：[屏幕五子棋](../../../docs/user_program/gomoku-screen/README.md)。
