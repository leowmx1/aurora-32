# Text Viewer / Editor

User-mode directory browser and line editor using `system.fs` and keyboard callbacks.
Build with `user-programs/build.ps1 -Program txt-viewer`, then repack storage.
Run `txt-viewer` in the system console. Start with `open docs/notes.txt`.

Full commands, save limitations and examples: [documentation](../../../docs/user_program/txt-viewer/README.md).
