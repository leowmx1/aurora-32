# 迷宫探险

源码：`user-programs/programs/maze/maze.c`。
用户态运行，键盘由硬中断回调入队，主循环处理移动；保留正常 tick 调度。

## 构建与运行

项目根目录执行 `./build-tools/build.ps1 -Program maze`。
将 `kernel/build/kernel.hex` 加载到 ROM，
`user-programs/programs/maze/build/maze.hex` 加载到 UROM，再复位。
若内核已经是当前版本，可用 `./user-programs/build.ps1 -Program maze` 单独构建。

## 操作与地图

| 按键 | 功能 |
|---|---|
| W/A/S/D | 上/左/下/右，小写也可以，无需回车 |
| R | 原地图回到起点，步数及计时归零 |
| N | 生成新地图并重新开始 |
| Q | 退出码 0，交由内核输出日志并停机 |

`#` 是墙，空白是通路，`@` 是玩家，`S` 是起点，`E` 是出口。
整个地图为 15×11 个逻辑格，横向格间加空格，显示宽度 29 字符。
起点 `(1,1)`，出口 `(13,9)`；坐标从零开始，仅用于说明。
只有成功移动才计步，撞墙不计步、不刷新。抵达出口显示 `Escaped!`，退出码 0。
时间是从本局开始计的整数秒，包含停留和绘图时间，仅在重绘时更新，非实时刷新计时器。

## 算法与系统接口

以 7×5 个房间为节点，使用显式栈执行随机深度优先搜索，在相邻房间间打通墙。
全部房间连通且无环，因此任意房间到出口都有唯一路径。不使用递归、堆内存或 libc。
随机数为 xorshift32，初始种子来自 `system.TimeMs()`；同种子生成同地图，非密码学随机。
零种子会替换为固定非零值。新地图混合当前随机状态和系统时间。

通过 `system.io.buffer` 批量输出，每批最多 64 字，缓冲区位于全局用户 RAM。
键盘使用正式 `aurora_kbqueue.h` 库：`kbqueue.Init()` 订阅回调，主循环用 `kbqueue.Next()` 取字符。
回调只向 64 槽环形队列入队（可用 63 槽），Next 校验 `0xA5SSSSCC` 后返回字符。
队列满会丢弃待处理输入并提示，不回放可能已经过时的移动。键盘回调忙时内核仍可能丢键。
无设备 MMIO、用户特权指令或键盘 GetChar 轮询。
