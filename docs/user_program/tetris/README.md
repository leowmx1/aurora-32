# 屏幕俄罗斯方块

源码：`user-programs/programs/tetris/tetris.c`，产物在同目录 `build/`。
系统终端命令 `tetris` / `run tetris`，可信镜像可用 `quickrun tetris`。
本地或远程启动皆可；远程运行的画面仍在 Digital 显存窗口。

## 画面与操作

棋盘为 **10×20 格**，格子占 **4×4 像素**，内部绘制 3×3 彩色块并留一像素间隔。
棋盘左上角 `(58,8)`，大小 40×80，带边框；背景采用低饱和度深色，七种方块分别着色。
左侧 S 表示分数、L 表示累计消行，右侧 N 为下一块预览、P 为等待/暂停状态（1 暂停，0 运行）。
分数和行数在屏幕显示低六位，内部为 32 位无符号计数。

| 按键 | 动作 |
|---|---|
| SPACE | 初始开始；运行时顺时针旋转 |
| A / D | 左右移动一格 |
| W | 硬降并立即锁定 |
| S | 向下移动一格，不能下移则锁定 |
| P | 暂停/继续；暂停期间不移动、不累计下落时间 |
| Q | 退出并返回所属系统终端 |

字母大小写均支持，无需回车；不实现方向键转义序列。终端仅启动打印帮助、结束打印结果，
游戏过程中不逐步打印。旋转尝试原位置、左1、右1、左2、右2；这是简化墙踢，不是完整 SRS。
无暂存方块、影子、锁定延时、T-spin 或多人模式。

## 规则

七种四格方块采用 7-bag 洗牌，每袋每种恰好一次，使用启动 timer 作随机种子。
随机数不是密码学随机；模拟复位时相同时间种子可能产生相同序列。
满行一次性压缩，连续多行不会漏消。新方块出生位置被占用即结束。
一次消 1/2/3/4 行分别得 100/300/500/800 × 当前等级倍数（已消行数/10+1）；
软降每格 1 分，硬降每格 2 分。初始每 500 ms 自动落一格，每 10 行减 50 ms，最快 100 ms。
绘制或调度很慢时不无界补算历史步数，优先保证可响应的游戏状态。

## 性能及稳定性约定

- 仅启动清全屏；移动比较 200 格的软件图层，只重画改变的格子。
- 分数等文字使用 6×10 位图；数位变化才重画，预览变化才更新其 16×16 区域。
- 回调只更新游戏状态，主循环负责绘图；通过 DeferEvents/ResumeEvents 保护渲染快照，
  不禁用硬件中断，不使用用户态特权指令，不维护第二个键盘队列。
- 未开始/暂停用 WaitEvent；运行中用可被输入提前唤醒的 Sleep 等待下落。
- GPU 保持现有 Busy/Yield 轮询协议；超过 10 秒退出，输入队列溢出也安全报错退出。
- 固定数组，无递归/堆分配；`.noinit` 工作区在使用前明确初始化，不依赖上一程序留下的 RAM。

```powershell
.\user-programs\build.ps1 -Program tetris
.\build-tools\pack-storage.ps1
```

需要当前内核和存储镜像。全构建：`.\build-tools\build.ps1`。
`tests/tetris/run_tetris.py` 执行编译后的算法自测及正式游戏 BIN，覆盖四次旋转、墙踢、边界、
七袋随机、落地锁定、单行/四行消除、计分、出生堵塞、暂停、硬降、绘制范围、差量更新及休眠。
测试不是 Digital 微码/电路时序验证。
