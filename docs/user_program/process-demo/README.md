# Process demo：前后台多进程示例

`process-demo` 是安静运行 60 秒后以代码 0 退出的用户程序。时间来自 Aurora 的 timer，
不是宿主机墙钟；慢速电路仿真可能实际等待更久。

```text
process-demo &
ps
calculator
```

本地后台运行计时任务，前台仍可使用计算器。远程终端也可执行同样两条启动命令，
得到四个用户进程。后台任务退出时所属终端会立即显示程序名、槽位、银行和退出码，
计算器继续运行。`ps` 可从空闲系统终端查看，`kill SLOT` 可提前终止。

直接执行 `process-demo` 为前台模式，可按 Q 提前退出。后台没有键盘输入，订阅返回
EBUSY 是正常结果；后台任务按 timer 自动结束，不会抢走系统命令行或计算器的按键。

程序每次通过 `system.Sleep(1000)` 阻塞，不忙轮询。跨越休眠保存局部栈值和全局哨兵，
检测明显的上下文或银行串写；失败以代码 1 退出，前台模式还输出说明。这不是穷尽内存诊断。
前台正常运行只打印一次启动说明，之后由内核报告退出；后台用户输出被内核静默丢弃，
只显示内核的启动/退出通知，不干扰前台交互。

构建：`./user-programs/build.ps1 -Program process-demo`，随后
`./build-tools/pack-storage.ps1`。完整构建 `./build-tools/build.ps1` 已包含它。
