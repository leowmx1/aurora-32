## 构建检查

每个目标通过以下检查：入口首字 JMP，目标位于对应 ROM/UROM 且位于实际镜像内；
二进制大小按 32 位字对齐；没有未定义符号或未解决的重定位；用户汇编没有
EI/DI/HALT/IRET/PUSHU/POPU；HEX 头为 `v2.0 raw`。
本次解析到的系统调用 ROM 字地址是 `0x00000FD1`，仅为此版本结果，脚本未硬编码它。

## 限定范围

验证对象是当前三个用户源程序与计算器跟踪变体。历史已缺失示例没有伪造源码或产物。
旧 customasm 裸机汇编不是本工具包的兼容性验收目标。
没有通过这次文档整理更改计算器算法、棋局规则、猜数字规则或内核调度逻辑。
键盘实际触发、微码状态切换、异常电路及 CPU 运行稳定性需要在 Digital 中另行验证。
